How ModelRoute handles a request

Protect
Redis-backed atomic token-bucket rate limiting controls request volume.
02

Fixed, cheapest, or latency-aware selection chooses an eligible provider.
03
Cache
Redis reuses exact effective requests; different wording creates a different key.
04
Execute reliably
Timeout, bounded retry, and provider fallback contain upstream failures.

Observe
PostgreSQL stores request telemetry without raw prompt or response content.
